# 🚀 Futures Arbitrage Analyzer (Perpetual Swaps)

Ветка: `feature/futures`  
Статус бота: **Не подключен** (логика готова к интеграции)

Данный модуль предназначен для поиска арбитражных окон между **бессрочными фьючерсами (Perpetuals)** на различных криптобиржах.

---

## 💡 Стратегия: Delta-Neutral Arbitrage

В отличие от спотового арбитража, эта стратегия не требует физического перевода активов между биржами.

1. **Обнаружение**: Поиск пары бирж, где на одну и ту же монету (напр. `RATS/USDT`) возникла значительная разница в цене.
2. **Вход**: 
   - **LONG** на бирже с низкой ценой.
   - **SHORT** на бирже с высокой ценой.
3. **Профит**: Извлекается при схождении цен (схлопывании спреда) или за счет разницы в ставках финансирования (Funding Rate).

---

## 🧮 Константы и Оптимизация

Для минимизации рисков ликвидации и убытков на комиссиях установлены следующие оптимальные параметры:

| Параметр | Значение | Описание |
| :--- | :--- | :--- |
| `LEVERAGE` | **x6** | Золотая середина. Ликвидация наступает при отклонении цены на ~16.5%. |
| `THRESHOLD` | **0.6%** | Минимальный "грязный" спред. Отсекает сделки, которые уйдут в минус после комиссий. |
| `EST_FEE_TOTAL` | **0.22%** | Суммарная комиссия за полный круг (вход/выход на двух биржах по Taker-fee). |
| `MIN_VOLUME_USDT`| **$5,000,000**| Защита от неликвидных щиткоинов с огромными стаканами. |
| `SIGNAL_TTL` | **5 сек** | Время подтверждения сигнала. Фьючерсные окна живут недолго. |

## 📈 Формулы расчета

### Чистый спред (Net Spread)
Учитывает реальные затраты на торговлю:
$$Spread_{net} = \left( \frac{Price_{short}}{Price_{long}} - 1 \right) \times 100 - Fee_{total}$$

### Доходность на капитал (ROE)
Показывает процент прибыли к задействованной марже с учетом плеча:
$$ROE = Spread_{net} \times Leverage$$

*Пример: При спреде 1% и плече x6, чистый ROE составит примерно **4.68%** за сделку.*

## 🛠 Технические требования

1. **Данные**: Collector должен быть переведен в режим сбора фьючерсных тикеров (`defaultType: 'future'` в CCXT).
2. **Redis**: Хранит временные метки сигналов для предотвращения ложных срабатываний.
3. **Безопасность**: Перед запуском авто-торговли необходимо добавить проверку **Funding Rate** (не входить в Short при аномально высоком положительном фандинге).
